# Project 01: AI Lead Management System

## Project Overview

This project aims to build an AI-powered lead management system for a real estate business using n8n.

## Business Problem

Real estate businesses receive enquiries from potential customers through different channels. Manually reviewing, organising and following up on these enquiries can be time-consuming.

## Proposed Solution

An automated workflow that receives enquiries, extracts relevant information, classifies potential customers and notifies the sales team.

## Planned Technologies

- n8n
- OpenAI or Gemini API
- Google Sheets
- Webhooks
- JSON

## Planned Workflow

1. Receive customer enquiry.
2. Extract customer information.
3. Analyse and classify the enquiry using AI.
4. Store the lead information.
5. Notify the sales team.

## Project Status

Planning stage — implementation not yet started.
